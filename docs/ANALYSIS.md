# Análisis local de gastos

Saldo Nube muestra un resumen de gasto por categoría a partir de los movimientos almacenados y cifrados en el dispositivo. El cálculo se realiza localmente: no se suben movimientos, contraseñas ni resultados a un servicio externo.

## Qué responde

El resumen permite observar cuánto gasto se ha registrado en cada categoría. Úsalo para detectar categorías que merece revisar, contrastar un presupuesto mensual o preparar un objetivo de ahorro.

No demuestra por sí solo una causa ni predice gastos futuros. Un total alto puede deberse a una compra puntual, a registros incompletos o a un periodo de tiempo distinto.

## Antes de sacar conclusiones

1. Comprueba que el periodo que quieres comparar contiene los movimientos relevantes.
2. Revisa que cada movimiento tenga categoría y que no haya duplicados.
3. Separa los gastos extraordinarios de los recurrentes antes de decidir un presupuesto.
4. Compara varios periodos equivalentes cuando sea posible.

## Límites

- Los resultados dependen de datos introducidos manualmente; no hay conexión bancaria ni conciliación automática.
- La aplicación no ofrece recomendaciones personalizadas de inversión, compra, venta o contratación de productos financieros.
- Para analizar un CSV u otra exportación, revisa primero columnas, fechas, valores vacíos y duplicados. No compartas datos personales o financieros reales con servicios externos sin autorización expresa.

## Próximo análisis útil

Cuando exista una muestra suficiente de datos locales, compara el gasto de cada categoría entre periodos equivalentes y anota primero las diferencias verificables; después decide si merece ajustar el presupuesto u objetivo correspondiente.
